# WEB

Sitio web del servicio de creacion de paginas web.

Estado: en desarrollo local. El despliegue se realizara cuando el sitio este listo.

## Entorno

- Node.js 24
- npm 11
- Git 2.54

## Notas

La carpeta `node_modules` es un enlace de directorio (junction) hacia
`C:\dev\cache\proyecto-web\node_modules`, para evitar que OneDrive
sincronice decenas de miles de archivos. Si se clona este repositorio en
otro equipo, basta con ejecutar `npm install`.
